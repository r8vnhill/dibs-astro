The original plan is well scoped. This version improves it by:

1. **gating generation behind tests**;
2. **running check mode immediately after update mode**;
3. **making traceability status dependent on successful verification**;
4. **removing optional phase-note creation from the default path**;
5. **correcting the purity check for `package.json`**: it should be inspected for exactly the three intended script
   additions, not treated as an empty protected diff.

DDT is useful for the package-script matrix and notice-content checklist. PBT is not useful here because the work is
deterministic: fixed scripts, a frozen manifest, and a generated baseline.
