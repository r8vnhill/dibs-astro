# @ravenhill/phosphor-icons

Phosphor icon SVG assets for Ravenhill projects.

## Overview

This package exports 1,521 Phosphor icon SVG files as Astro SVG components (`AstroComponentFactory`). It is designed for
use in the Astro 5 ecosystem where `.svg` imports are natively transformed into renderable components.

## Usage

### In Astro Projects (via path alias)

The Ravenhill Astro app consumes this package through the `$icons` path alias, which points to the package source:

```astro
---
import * as icons from "$icons";
---

<div>
    <icons.Acorn />
    <icons.BookOpen />
</div>
```

### In Standalone Projects

First-party packages or external consumers can import from the published npm package:

```ts
import { Acorn, BookOpen } from "@ravenhill/phosphor-icons";

// Use as Astro components in Astro files, or wrap for other frameworks
```

## Architecture

- **Source**: `src/` contains 1,521 SVG files + auto-generated `index.ts` barrel
- **Build**: tsup externalizes SVG imports; `copy-assets.mjs` post-build copies SVGs to `dist/`
- **Distribution**: `dist/` contains both the re-export barrel and all SVG files
- **SVG pipeline**: Consumers must have an SVG loader compatible with Astro's native SVG support

## Building

```sh
pnpm build
```

This runs:

1. `tsup` — emits `dist/index.js`, `dist/index.d.ts`, and source map
2. `scripts/copy-assets.mjs` — copies 1,521 SVGs from `src/` to `dist/`

## Validation

```sh
pnpm check
```

This runs all checks: build, typecheck, lint, and pack validation.

## Icon Index

The barrel file is auto-generated by the root `generate-icons-index.js` script. Run from the monorepo root:

```sh
pnpm generate-icons
```

Do not edit `src/index.ts` manually.

## Publishing

This package is published to the Ravenhill GitLab npm registry. It is not published to npm.org.
